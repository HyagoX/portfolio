# Elegant Portfólio Hub

Atue como um Desenvolvedor Web Front-end Sênior e especialista em UI/UX. Preciso que você crie o código completo (HTML, CSS e JavaScript) de uma página única (Single Page Application) para o meu portfólio pessoal. O design deve ser extremamente elegante, moderno e minimalista.

Estilo e Tema:

Tema totalmente escuro (Dark Mode), utilizando uma paleta de cores focada em Preto, tons de cinza escuro (para criar profundidade) e Branco (para textos e destaques).

Tipografia limpa (sans-serif) e contrastes bem definidos para transmitir sofisticação.

Estrutura das Seções:

Header/Menu: Um menu de navegação fixo no topo com links suaves para as seções abaixo.

Seção Hero: Um espaço chamativo de introdução. Deve ter um espaço redondo e estilizado para a minha foto de perfil, meu nome, e um texto de impacto explicando o meu trabalho: "Especialista em desenvolvimento de Landing Pages simples, rápidas e de alta conversão".

Seção Sobre/Habilidades: Uma apresentação visual das minhas tecnologias. Inclua tags ou ícones modernos para: HTML, CSS, JavaScript, Python e Ferramentas de Inteligência Artificial.

Seção de Projetos (Placeholder): Um grid com 3 "cards" de projetos fictícios com título, breve descrição e um botão "Ver Projeto", para que eu possa substituir com meus trabalhos reais depois.

Seção de Contato (Funcional): Um formulário de contato contendo campos para Nome, E-mail e Mensagem. Prepare a estrutura do formulário utilizando um serviço como o Formspree ou EmailJS, apontando para o e-mail: hyagojmaria@gmail.com, para que eu receba as mensagens diretamente na minha caixa de entrada sem precisar configurar um backend complexo do zero.

O código deve ser responsivo (funcionar perfeitamente no celular) e ter animações suaves (scroll suave, efeitos de hover nos botões e nos cards). Forneça o código devidamente comentado.
